### NC-1117-01｜EF 数据库工具未随交付物提供，新机部署必失败

| 字段 | 内容 |
| --- | --- |
| **问题描述** | `backend/.config/dotnet-tools.json` 文件缺失，部署文档（docs/deployment.md 环境要求表）未声明 `dotnet-ef` 工具的安装步骤。全新机器安装 .NET 8 SDK 后执行 `dotnet ef database update` 报「无法执行，找不到命令」，后端无法完成建库，部署链路在第一步即中断。本机因已全局安装 dotnet-ef 8.0.32 而长期掩盖此缺陷 |
| **违反条款** | 需求说明书 v2 第 5 节（交付与验收要求）：「提供依赖安装说明、数据库迁移方法」；README_交付说明：开发者需提供「本机一键启动或清晰的启动命令」 |
| **业务模块** | DEP（部署与交付） |
| **责任人** | 成员A |
| **发现日期 / 来源** | 2026-11-17 ｜ 甲方环境部署失败反馈（截图） |
| **严重等级** | 重大(A)——直接导致甲方侧部署失败 |
| **整改措施** | ① 新建 `backend/.config/dotnet-tools.json`，锁定 dotnet-ef 8.0.32；② deployment.md 第 2 节首条命令改为 `dotnet tool restore`；③ README 快速开始补充「全新机器先 dotnet tool restore」前置说明 |
| **整改完成时间** | 2026-11-17 |

| **责任人** | 成员A |
